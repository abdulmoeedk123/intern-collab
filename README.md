# Crew Board: real-time Kanban for interns (MERN + Socket.IO)
1. `cd server && cp .env.example .env && npm i && npm run dev` (needs MongoDB running)
2. `cd client && npm i && npm run dev`, then open http://localhost:5173
3. Register two interns in two browsers, create a project, invite the other by email, and watch tasks and milestones sync live.
